# Rationalization Platform

Проект о рационализации цифровой экосистемы: повторном использовании, объединении и адаптации уже существующих решений. Репозиторий содержит концептуальное предложение и отдельную платформу с backend, frontend и Docker-конфигурацией.

Начните с `rationalization-proposal.md` или `rationalization-platform/README.md`.
